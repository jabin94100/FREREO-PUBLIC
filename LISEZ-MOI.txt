LES FRÉR'O — V29 / Envoi de devis SMTP2GO

1. Hébergement : PHP 8.1+ avec HTTPS sortant (cURL recommandé, ou allow_url_fopen et OpenSSL).
   Mettre le contenu de public/ dans la racine web (souvent public_html ou www).
   Garder private/ au même niveau que public_html/www, jamais dans la racine web.
   Le dossier private/ doit être accessible en écriture au processus PHP pour les limites de débit.
   Si l'arborescence diffère, adapter $private dans envoyer-devis.php.
2. Dans SMTP2GO : Sending > Verified Senders, valider frer-o.com (recommandé) ou contact@frer-o.com.
   Appliquer les enregistrements DNS indiqués par SMTP2GO si vous validez le domaine.
3. Sending > API Keys : créer une clé avec la permission email/send uniquement, limiter son débit.
   Définir SMTP2GO_API_KEY dans l'environnement serveur OU copier private/smtp2go.example.php
   en private/smtp2go.php et remplacer la valeur fictive par la clé. Restreindre les droits d'accès.
   SMTP2GO_SENDER (facultatif) permet de changer l'expéditeur vérifié. Le destinataire reste contact@frer-o.com.
   Ne jamais coller la clé dans index.html, un JS public, un dépôt ou une conversation.
4. Ouvrir le site via HTTPS, remplir le formulaire et vérifier l'arrivée du message dans la boîte de réception.
   Le Reply-To est l'adresse du client. Le formulaire confirme l'acceptation par l'API, pas la livraison finale.
   Contrôler également l'activité SMTP2GO. SMTP2GO n'est pas un hébergeur de boîte de réception.
5. Le fichier HTML autonome sert à prévisualiser le site, pas à envoyer un vrai mail.

Protection de base : champ piège, validation serveur, destinataire fixe, limitation à 4 demandes/15 min/IP et 30/h au total, sans stockage des messages côté site. Nettoyer périodiquement les anciens fichiers private/rate/ (après expiration). Si le site est derrière un proxy, adapter la limitation IP à la configuration de confiance de l'hébergeur. En cas de spam, envisager un CAPTCHA ou une protection supplémentaire côté hébergeur. Compléter les mentions de confidentialité (durée de conservation, droits, prestataire SMTP2GO) avant publication.

Documentation : https://developers.smtp2go.com/docs/getting-started
